# 连续与混合整数线性规划

## 建模步骤

先用清楚的名称声明决策变量及其单位和变量域，再将一个最大化或最小化目标写成线性表达式。资源限制、需求下限和守恒关系分别写成线性不等式或等式。

变量下界和上界若影响可行域，必须作为明确约束给出；不能因为某些示例常见非负变量，就自行给未说明的变量添加非负限制。

## 变量域与单位

当前模型支持连续、整数和二进制变量。二进制表示只能取 0 或 1 的选择，整数表示不可分割的数量。变量单位应与目标系数、约束系数共同解释，避免将件、小时和费用等不同量纲直接混算。

当前线性输入模型不保存目标单位、系数单位、上下界元数据或自然语言事实编号；转换到统一 IR 时，这些未提供的信息保持为空，不自动推断。

## 当前适用边界

当前求解器适配器支持单目标连续 LP 和 MILP。非线性、随机、多目标以及无法转换成线性约束的规则不在此卡适用范围内；若问题包含这些要求，应说明限制或请求用户改写，而不是删去约束后继续求解。
