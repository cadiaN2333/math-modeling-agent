# 求解器能力与选择边界

## 连续线性模型

所有变量均为连续变量时，求解器注册表优先选择 OR-Tools GLOP。变量域、目标方向、线性项、约束关系、常数项和上下界必须完整传递。

## 整数与二进制模型

含整数或二进制变量的通用线性模型使用 SCIP。排班模型在变量均为整数/二进制、整数系数可精确表达且变量界有限时优先使用 CP-SAT；整数数据不能满足 CP-SAT 数值要求时，注册表选择兼容的 SCIP，不对系数四舍五入。

## 网络流模型

单商品整数最小费用流应保留为节点和有向弧结构，交给 OR-Tools SimpleMinCostFlow。供需、路线容量、单位费用和流量单位不得通过自然语言或求解器日志重新猜测。

## 不支持与数值范围

若没有已注册后端能精确表示模型，返回 `UNSUPPORTED_MODEL`。不得为了让后端接受模型而静默删除约束、忽略变量域或改变单位。CP-SAT 只处理有限整数变量界、整数系数及安全的 64 位表达式范围。
